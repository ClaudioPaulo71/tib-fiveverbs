# VER5S: AI-Powered Daily Verb Mastery

**VER5S** is a specialized language learning platform designed to help users master core verbs through focused, AI-generated daily lessons. By concentrating on just 5 verbs a day, the app ensures high retention and consistent progress.

## 🎯 Project Objective
The goal is to provide a seamless, habit-forming experience where users receive personalized lessons based on their interests and proficiency level. The app eliminates "learning fatigue" by leveraging Generative AI to create contextually relevant sentences, quizzes, and practice exercises every single day.

## 🚀 Key Features
- **AI-Driven Lessons**: Daily content generated by Google Gemini, tailored to user interests.
- **Persistence & Tracking**: Real-time auto-saving of progress across all devices.
- **Interactive Exercises**: Quiz questions and "fill-in-the-gap" practice for every verb.
- **Calendar Dashboard**: Visual history of completed lessons and scores.
- **Secure Auth**: Integration with Auth0 for social and email login.
- **Production Ready**: Optimized for VPS deployment using Traefik and Docker.

## 🛠 Tech Stack
### Frontend
- **React + Vite**: High-performance single page application.
- **Vanilla CSS**: Premium, custom-styled UI with glassmorphism and micro-animations.
- **Axios**: Robust API communication with auto-save synchronization.

### Backend
- **Django & Django REST Framework**: Scalable API architecture.
- **PostgreSQL**: Reliable data persistence for users and lessons.
- **Google Gemini**: Large Language Model integration for dynamic content generation.
- **Whitenoise & Gunicorn**: Production-grade static file serving and application server.

### Infrastructure
- **Docker & Docker Compose**: Containerized environment for consistent dev/prod parity.
- **Traefik**: Automated reverse proxy and SSL (HTTPS) management.
- **Auth0**: Externalized identity management.

## ⚙️ Quick Start (Development)
1. Clone the repository.
2. Create a `.env` file with your `AUTH0_*` and `GEMINI_API_KEY` credentials.
3. Run the application:
   ```bash
   docker-compose up --build
   ```
4. Access the frontend at `http://localhost:5173`.
